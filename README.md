# Giveaze Backend API

Production backend system powering the Giveaze donation platform.

Divakaran S (diva-sl)

## 🛠 Tech Stack

Server:
- Node.js
- Express.js

Database:
- MongoDB
- Mongoose ODM

Payment Gateway:
- Razorpay Integration
- Signature Verification

Queue System:
- Redis
- BullMQ
- Worker Processes

PDF & Email:
- HTML to PDF receipt generation
- Background email sending
- Queue-based processing
